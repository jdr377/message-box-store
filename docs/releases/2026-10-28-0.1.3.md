# Message Box Store 0.1.3 — 28 October 2026

Compatible security release from the accepted independent review and coordinator
validation. Changes: admission before body parsing, canonical recovery epochs,
byte-bounded browse, metadata-only snapshot capacity checks, and finite permanent
deletion-key reservations. The approved support statement is in
[UPGRADING](../UPGRADING.md#deployment-and-support).

Product fixes are committed as `a096271`; the support baseline is `5b4e082`.
The release changes only version/documentation. The dependency lock and SDK 4
graph are unchanged. No wire, ciphertext, wallet-key or database-schema migration
is introduced. Live data, owner-run services and wallet actions are untouched.

- Complete Store script: 342 passed, zero failures, 25 deliberately gated MySQL
  skips. Six new real MySQL scenarios and four existing MySQL integration cases
  passed separately on MySQL 8.4.13/InnoDB. Detailed scope is in the
  [independent review](../reviews/2026-10-28-independent-security-review.md#coordinator-acceptance--28-october-2026).
- Release build, typecheck, lint, five manifest/scaffold checks and the
  114-package ESM/CJS/browser/declaration archive check passed.
- 28 exact-archive consumer tests passed with official SDK 4.0.0 and no SDK
  override: authenticated mutation/isolation, replay rejection, redirect refusal,

- Fresh consumer production audit reported zero findings.
- No MapApp full-suite rerun is part of this release.
