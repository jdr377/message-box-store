## Prioritized opportunities

1. **Extract common feed preparation from the three repositories.** [`repository.mjs:637`](../src/repository.mjs), [`repository.sqlite.mjs:902`](../src/repository.sqlite.mjs), and [`repository.mysql.mjs:996`](../src/repository.mysql.mjs) repeat the checkpoint/cursor/W selection, retention-gap checks, and event projection before calling the already shared [`feeds.mjs:262`](../src/feeds.mjs) page assembler. A pure, storage-neutral preparation/projector could remove an estimated 100–200 nonblank lines and, more usefully, reduce three-way drift. Keep SQL selection, transaction and lock boundaries, timestamp normalization, and post-delete ciphertext fences adapter-specific. **Risk:** cursor error precedence, fixed-W semantics, and deletion privacy can change subtly. **Accept:** byte-identical pages/errors across adapters for existing conformance vectors, cursor tampering/expiry, interleaved writes/deletes, retention gaps, and `uint64` boundaries; MySQL concurrency proofs must still pass.

2. **Reduce duplicate service rules and plumbing.** [`service.ts:324`](../src/service.ts) holds rate/IP/replay guards; [`service.ts:1011`](../src/service.ts) configuration; [`service.ts:1214`](../src/service.ts) request validation; [`service.ts:1919`](../src/service.ts) cleanup scheduling; [`service.ts:2243`](../src/service.ts) middleware/routes; and [`service.ts:2992`](../src/service.ts) lifecycle. Its 3,041 nonblank lines exceed either SQL adapter. Consolidate equivalent defaults, predicates, guard flow, and lifecycle state where evidence supports it. A file split alone does not meet the refactor goal; only extract when the combined package-wide production source shrinks. **Risk:** middleware order, lazy imports, and `service.ts` exported names may change. **Accept:** preserve the `./server` exports and wire/error contracts, exact authentication/replay/rate/admission order, liveness/readiness, bounded cleanup and shutdown behavior; show a measured net source reduction and pass M2 focused tests, typecheck and packed server consumer checks.

3. **Narrow the published file inventory without removing test evidence from the repository.** [`package.json:94`](../package.json) includes all of `src` and `src/*.ts`, while the built `dist` is already packed. [`m0-message-box-fixture.mjs`](../src/m0-message-box-fixture.mjs) and [`m0-authsocket-fixture.mjs`](../src/m0-authsocket-fixture.mjs) are test fixtures totaling 19,234 source bytes and have no declared package subpath. TypeScript source in `src` totals 214,317 bytes, although public declarations come from `dist`. A carefully enumerated runtime-source allowlist could save up to roughly 233 KB unpacked before dependency/CLI requirements are subtracted; the compressed saving requires measurement. **Risk:** raw `.mjs` subpaths, relative runtime imports, source debugging, and operator restore scripts may need these files. **Accept:** preserve all `exports` targets and their transitive files, required recovery/runbook/notice files in [`pack-verify.mjs:72`](../scripts/pack-verify.mjs), M0 fixtures in the checkout for tests, and the packed ESM/CJS/browser/types/CLI checks. Compare before/after tarball inventory and sizes. Do not remove the required PRD/ADR or operator documentation merely to reduce the number: the current pack gate expressly requires them.

4. **Finish a uniform public subpath story.** [`package.json:51`](../package.json) exposes six raw `src/*.mjs` repository/feed/migration paths while `./`, `./client`, `./server`, `./storage`, `./protocol`, and `./canonical` use built ESM/CJS/declarations. [`storage.ts:1`](../src/storage.ts) describes a typed repository surface but does not provide declarations for each raw adapter path. Decide which raw paths are supported public API, add declaration and CommonJS entry coverage where promised, and make the package inventory follow that decision. This is primarily consumer clarity, likely adding some artifact bytes. **Risk:** replacing existing raw targets could break imports. **Accept:** retain existing ESM paths unless a versioned migration is authorized; compile small clean-consumer imports for each supported path and verify Node/browser separation. Do not pull Knex/MySQL into browser roots.

5. **Consolidate only truly duplicate shape rules.** [`service.ts:1214`](../src/service.ts) and [`protocol.mjs:117`](../src/protocol.mjs) repeat epoch/idempotency spelling; [`service.ts:1482`](../src/service.ts) and [`snapshots.mjs:34`](../src/snapshots.mjs) repeat filter shape decisions. Share predicates/constants while retaining HTTP-specific error mapping and the repository's per-record outcome boundary. Expected size win is small (tens of lines), but divergence risk falls. **Risk:** validation timing/status might shift—for example a batch-wide 400 versus a per-record outcome. **Accept:** strict shape, unknown-field, UTF-8 byte, 400/403/413, and schema/vector tests retain identical results. The full [`protocol.mjs:508`](../src/protocol.mjs) JSON Schemas remain necessary public contract evidence.

## Preserve the intentional weight

Three adapters are justified by the accepted memory/SQLite/MySQL test and production contract; MySQL's row locks and deadlock retry ([`repository.mysql.mjs:264`](../src/repository.mysql.mjs), [`repository.mysql.mjs:1134`](../src/repository.mysql.mjs)) should not be flattened into a generic transaction wrapper. Keep one-shot free-only transport protection ([`free-only-transport.mjs`](../src/free-only-transport.mjs)), BRC-103 ingress controls, signed fixed-watermark cursors, deletion fences, protocol schemas, recovery CLI, and third-party notices. The M0 fixture files should remain in the checkout for interop proof even if they leave the package tarball. `PRD.md`, `ADR-001-durable-history.md`, and the operator/security docs are currently pack-gated; any later documentation policy change needs an explicit release decision.

For implementation of `mbs-8g5.12`, compare the Store with `message-box-server` and `message-box-client` by responsibility as well as size. The server accepts a host-supplied Knex instance, but that alone does not prove Store supports arbitrary SQL dialects; assess dialect-specific migrations, locks, queries, and timestamp behavior before widening claims. Record before-and-after production nonblank LOC for each task and prefer a net reduction; explain any increase in terms of retained capability or improved structure. Measure packed size separately, and do not treat deleting tests or moving code between files as a LOC win. Run focused repository/service/worker tests, the complete MySQL-enabled suite with zero skips for database changes, and packed ESM/CJS/browser/types checks. Preserve public exports, wire formats, security controls, resource bounds, and the independent release/security gates. This refactor does not inspect or optimize for an individual application consumer.
